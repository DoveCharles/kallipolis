# What people say and think — every file in this folder is one category, named by its file (animals.txt is [animals]).
# Files can be sorted into subfolders at any depth: a category is still named by its file alone, so moving one never
# breaks anything (two files with the same name: the first is used, with a warning). The loader finds them through
# assets/text/index.txt, which serve.py rewrites itself — after adding or moving files without it running, run
# `python3 serve.py --index`, and commit index.txt so the deployed site sees them.
# The lists in text/people/ are categories too — [boynames], [girlnames], [unisexnames], [surnames], [nicknames],
# [moods], [loves], [hates] — their {traits} read as tags (a trait's effect, as a lean: {aggression = 2} leans toward the
# aggressive). Loves and hates are said with a small first letter, or as the wording after a | if there is one:
#   Whatever they think of next | whatever I think of next {nerd = 2}
#   Taylor Swift | Taylor Swift <media>                          (a | keeps a name's capital)
#   Their [pets#1: plural] | my [pets#1: plural] <nature>        (filled once per person: their card says "Their cats",
#                                                                 they say "my cats", and cats count as loved)
# In a love or hate, [ ] is a placeholder, as here; the spoken wording's placeholders take the card's picks in order.
# <CATEGORIES>: any entry in any file here or in people/ can join other categories as well as its own, with <names> last:
#   mouse | mice <pets, livestock>       (in animals.txt: also in [pets] and [livestock])
#   Nice weather. <smalltalk>            (a line shared into another topic; not on replies)
#   Energy drinks {stimulants = 2} <tastes, vice>
# A category is its file (if any) plus every entry tagged <with its name>: words/topics/tastes.txt is [tastes] — loves and
# hates tagged <tastes>, and whatever's written in the file itself. A category can also be <tagged> entries alone.
# Only files in speech/ and people/ are categories: the rest of assets/text/ (bees.txt, cars.txt, tv.txt...) is never
# read for speech, so [bees] or [cars] won't work. about.txt files are never categories either.
# Every category file is loaded at start. Speech starts from dialogue.txt (conversations), thoughts.txt (alone, as they fidget; no replies, shown but not said) and reactions.txt
# (straight after seeing a death), plus closers.txt (ending a conversation) fleeing.txt (called out as people run) and prayers.txt (said by someone praying, once clicked on). Blank lines and # lines are skipped.
#
# ------------------------------------------------------------------------------------------------------------------------
# LINES
#   Rhino                     a word or phrase
#   mouse | mice              a word with its forms (see FORMS)
#   I don't give a [swears].   a sentence; each [placeholder] is filled from that category when it's said
#   [pets]                    a line that's only a [category] includes all of that category's entries
#
# Includes nest as deep as MAX_DEPTH; a category that includes itself (even via others) is skipped with a warning.
# Placeholders within placeholders go 5 deep (FILL_DEPTH): at the fifth, only a word with no placeholders of its own is
# picked, so a category that names itself ("more [rec]") always ends.
# The same entry reached twice in one category (knife in both [weapons] and [utensils]) is kept once: the highest
# weight, and for each tag the strongest value (furthest from 0).
#
# ------------------------------------------------------------------------------------------------------------------------
# FORMS
# A word file names its forms once, at the top:
#   forms: singular | plural | general
# then each entry gives them in that order. Missing ones are worked out:
#   plural    made from the singular (rhino → rhinos, bus → buses, fly → flies); "-" means it has none
#   general   the thing in general ("I like knives", "I like cheese"): the plural if it has one, else the singular
# Verbs use:  forms: base | past | ing | third     (third, "she bites", made from the base when left out)
# Adjectives: forms: base | comparative | superlative   (made when left out: -er/-est, or more/most for a long word)
# An entry with no forms (a phrase like Fishing) gives itself for any form. A call for a form an entry doesn't have
# skips that entry.
#
# ------------------------------------------------------------------------------------------------------------------------
# CALLING A CATEGORY:  [category: option, option]   (options in any order)
#   [animals]                 the first form
#   [animals: plural]         a named form (plural, general, past, ing, ...)
#   [animals: a]              with a/an in front: "a rhino", "an owl"
#   [loves: lower]            its first letter made small, for lists written with capitals (people/'s): "I love energy drinks"
#   [colours: capitalise]     every word's first letter raised, for a list written small: "Red", "Blue" ("flat-pack" reads
#                             "Flat-Pack") — the casing the capitalise trait gives a card; with lower as well, lower wins
#   [interests: hated]        a negative call: flips the leaning (see TAGS), so good people pick evil things, and uses the
#                             speaker's hates where it'd use their loves (see LOVES AND HATES) — "I really hate [interests: general, hated]"
#   [bad: superlative]        "worst"; [violence: past] "punched"; [badhabits: third] "bites"; [foods: general, lower]
#   [pets#1]                  the same pick every time #1 is used, for the whole conversation — a reply can say
#                             [pets#1: general] and mean the same pet ("a dog" ... "dogs")
#   [folk#4: he]              the word's pronoun instead of the word, by its {sex}: he / she / they (they with no
#                             {sex}). Also him (him/her/them), his (his/her/their), himself (himself/herself/themself)
#                             and he's (he's/she's/they're). Mostly on a held #n, to talk about who it was.
#   No repeats: a new pick is never a word already picked in the same line, or one held as any #n in the conversation
#   (so [folk#1], [folk#2], [folk#3] are three different people). Saying a held #n again ([pets#1]) is still the same
#   word, as above. A category with too few words left can't be filled, and the line isn't said.
# The first letter of a line is capitalised when it's said, and the first after any . ! or ? (not an ellipsis …) — so write words in lower
# case ("labubu!!!" mid-line makes the next word start with a capital), and proper nouns with their capitals.
# Nothing is ever made lower case for you (it can't tell a name from a word), so a capital in a file comes out as written.
#
# ------------------------------------------------------------------------------------------------------------------------
# TAGS: {…} after any entry, include or reply
#   {weight = 3}              how often, next to its neighbours (default 1; on an include it multiplies every entry it brings)
#   {evil}                    leans toward speakers high in that trait (same as evil = 1); any trait from people/about.txt
#   {patience = -1}           leans toward speakers low in it
#   {nosy, chatty = 0.5}      several at once: leans toward the nosy, and a little toward the chatty
#   {aggression = -0.5, mood} a little toward the gentle, and toward the cheerful (mood, not happy: face states like
#                             happy, sad, goofy are rare and short-lived, so a lean on them does next to nothing)
#   {effect.speed = 2}        what the word does to someone whose love or hate it fills ("Taking [drugs]" filled with
#                             "ayahuasca {effect.blazed, effect.speed = 0.8}" gives them those): the same values as
#                             {traits} in people/ files (a multiplier, an amount to add, or on). Only counts there —
#                             said anywhere else it does nothing, and it's always as written. Leans never become
#                             effects. (A love or hate filled into another brings its own {traits}: see NOTES.)
#   {limit = 1b}              a hard limit, the same rules as in people/ files (their limits count here too): nobody
#                             holding the other side (1a) — through their name, mood, loves or hates, a vampire's 1a
#                             say — says a line or picks a word marked 1b, so a vampire never says they love the sun.
#                             In a [x: hated] call it's checked the other way: nobody picks what's on their own side
#                             (they won't say they hate the night). {likes} counts the other side as disliked (-1).
#   {evil = 2}                tags can go past 1: twice as hard a lean (the speaker's own level is always -1 to 1)
#   {appeal = -1}             how liked it is generally, whoever's speaking: -1 shunned by everyone, 1 liked by all.
#                             It adds into the same lean as the trait tags, so a tag can override it for some:
#                             Dying {appeal = -1}  nobody       War and famine {appeal = -1, evil}  nobody but the evil
#                             Loves count as {appeal = 0.3} and hates {appeal = -0.3} unless they give their own
#                             (in their {braces}: Taylor Swift {appeal = 0.5}); on an include it's added to everything
#   {man}  {man = -1}  {woman = 0.5}   sex, as a trait: man is +1 for men, -1 for women (woman the reverse; 0 for cuboid people)
#   {man > 0}  {woman > 0}  {other.man = 1}  {other.woman > 0}   only men / only women / leaning toward talking to men / only to women
#   Each trait's value is measured from its neutral (0, or 1 for traits that multiply) toward its max or min, so every
#   trait counts the same, -1 to +1.
#   On an include line, tags are added to every entry reached through that line only: [knives] {evil = 0.5} in
#   weapons.txt makes knives evil as weapons, not as cutlery.
#
# WORLD: prefix world. — soft with =, hard limits with comparisons, ranges and names (the line can't be picked unless they hold)
#   {world.morality = -1}     likelier the worse the player's morality (-1 worst to 1 best, the meter over its max)
#   {world.morality < -0.3}   only while morality is below -0.3 (also >, <=, >=)
#   {world.hour 22-5}         only from 10pm to the end of 5am (whole hours, both ends included; wraps past midnight)
#   {world.morality > 0.3}    only while morality's good
#   {world.hour 6-11}         only in the morning          {world.hour 22-3}  only late at night
#   {world.weather = rain}    only while it's raining (rain, snow, cloud, clear)
#   {world.weather = snow, mood = -1}  only in snow, leaning toward the gloomy
#
# HERE: where the speaker is (hard limits)
#   {here.indoors}            only inside a building          {here.outdoors}   only outside
#   {here.building = pub}     only inside that kind of building (a kind from buildings.txt: house, shop, pub, salon,
#                             clothes, convenience, restaurant, terrace...) or room (home, office, pub, salon, clothes,
#                             convenience, restaurant,
#                             warehouse, factory)
#                             (a salon's a nineties hair salon: mirrors, hood dryers, a fish tank, posters of big hair;
#                             everyone in one's there for a haircut, sat in a chair in front of a mirror; the cutting's
#                             done by a salon bot that pops up out of a hatch in the floor behind the chair, cuts their
#                             hair, and sinks back down — buildings/salonbot.js)
#                             (a clothes shop has rails of clothes, a till and changing rooms with curtains, and
#                             everyone in one's there to try something on)
#                             (a convenience store, here.building = convenience, is a 24-hour corner shop, open all night:
#                             aisles, drinks fridges, an ice cream freezer, a slushie machine, coffee, a hot dog roller,
#                             scratchcards and cigarettes behind the counter, a pharmacy corner under a green cross, an
#                             ATM, umbrellas by the door; everyone in one looks round, then pays at the till)
#                             (a restaurant's an old New York Italian joint: checked tablecloths, candles in Chianti
#                             bottles, red leather booths, a bar, a mural of Naples, signed photos — here.building =
#                             italian for only those — or a Greek taverna, here.building = greek: whitewash and blue,
#                             blue-checked cloths, rush-seated chairs, ouzo, a mural of Santorini, painted plates,
#                             grapevines overhead — or a kaiten sushi bar, here.building = sushi: plates going round on
#                             a belt (the plate's colour its price), stools round it, a chef at a bar, paper lanterns;
#                             in any most sit down and eat, and leave once they've eaten)
#                             (an office's corporate cubicles, here.building = corporate, or a startup's open plan,
#                             here.building = startup: bench desks, felt screens, kombucha on tap, beanbags, table
#                             tennis, salt lamps and crystals)
#                             (a pub always has music on — audio/pub-music.js — so pub lines can talk about it)
#                             (and a bar bot behind the bar — buildings/barbot.js — polishing glasses, wiping the bar,
#                             and asleep when nobody's in; anyone sat at the bar may talk to it, and it babbles back)
#   {here.building = craftpub} only in a craft beer bar: a pub (so pub lines are said there too) done up loud — bright
#                             walls, neon signs (HOPS, IPA...), strings of coloured bulbs, long shared tables, barrels
#                             to stand at, chalkboards of beers; no fire, no carpet, no fruit machine (see pubStyleOf)
#   {here.building = ensuite} in any home (the same as home: every one has a bedroom through an open doorway
#                             off the living room — a double bed, wardrobes, a dresser, carpet — and an ensuite at one
#                             end of it: toilet, basin, a glass shower — see homeSuiteOf)
#   {here.park}               only in a park — or here.plaza, here.beach, here.marina (hangouts; a marina's jetties too), here.roadside (on a pavement by a
#                             road), here.path (another walkway), here.bridge (a raised one), here.crossing (crossing a road)
#                             or here.foodcourt (a mall's food court: tables and chairs, palms and lamps under a glass dome)
#   {here.town}               only standing in a zone of that type — plain, park, water, beach, farmland, suburbs, town,
#                             plaza, city, industrial, airport, marina, mall, carpark (outdoors; on its roads and pavements too — a
#                             mall, drawn as a path, counts as outdoors: its glass-roofed concourse, galleries, bridges and escalators,
#                             but not the shops off them, which are here.building = clothes, salon, pub, restaurant or convenience)
#   {here.building = home, world.hour 23-4}   at home, late        {here.bridge}   on a bridge
#   {here.crossing}           crossing a road                 {here.city, world.hour 22-4}   in the city at night
#
# TRAITS AS LIMITS: compare a trait's level (-1 at its min, 0 neutral, +1 at its max) — hard limits
#   {evil > 0.5}              only speakers more than halfway to fully evil
#   {patience < 0}            only the impatient
#   {speed < 0}               only the slow                   {vampire > 0}   only vampires
#   {evil > 0.5, aggression}  only the very evil, leaning toward the aggressive of them
# AGE: their age in years (not agemult, which only scales how old someone turns out)
#   {age > 60}                only speakers over 60          {age < 30}   only under 30
#   {other.age > 70}          only to someone over 70        {other.age < 25, nosy}
#   {age}  {age = -1}         a lean toward the old / the young (18 counts as -1, 80 or more as 1)
#
# OTHER: the person they're talking to (whoever said the line being replied to, else whoever they're facing)
#   {other.fidgety}           leans toward talking to fidgety people (other.trait = n, as for the speaker's own traits)
#   {other.speed > 0.3}       only when the other person is fast (a hard limit; never true in a thought, with nobody)
#   {other.fidgety > 0.3}     only to someone twitchy         {other.aggression > 0.3}   only to someone aggressive
#   {other.is = sad}          only when the other person looks upset (see IS) — "> Why are you crying? {other.is = sad}"
#   {other.is = bloody}       only to someone covered in blood — "Is that blood on you?! {other.is = bloody}"
#   {other.is = drunk}        "> I think you've had enough. {other.is = drunk}"
#   {other.is != happy}       only when they're not looking happy
#   {other.friend}            only to a friend (they feel above 20 about them: the person card's Social tab)
#   {other.enemy}             only to an enemy (below -20)
#   {other.introduced}        only to someone they've finished a conversation with before
#   {other.stranger}          only to someone they haven't: "Hi, I'm [me.name]. {other.stranger}"
#   {seen.friend} {felt.enemy}...  the same about who they saw it happen to, or who did it to them
#
# LIKES: how much the replier likes a word picked in the line they're answering, -1 to 1 — 1 if it's one of their loves,
# -1 one of their hates, else the word's own {tags} read against their traits (0 for a word without tags)
#   {likes}                   leans toward repliers who like the last word picked in the line above: "I love killing"
#                             ({evil} in vice.txt) gets "> Me too! {likes}" from the evil, and now and then from the good
#   {likes = -1}              leans toward those who dislike it      {likes = 0.5}   a gentler lean
#   {likes > 0}               only if they like it (hard)            {likes < 0}     only if they dislike it
#   {likes > 0.5}             only if they like it a lot             {likes #1 < 0}  about the word held as #1 instead
#   {likes = -1, aggression}  disliking it, leaning toward the aggressive
#
# PICK TAGS: {likes} is one of these; the same works for any measure of any held word(s).
#   Measure (what's read from each word, about -1 to 1):
#     likes                   how much the speaker likes it (above)
#     appeal                  the word's own {appeal}
#     a trait (evil, ...)     the word's own tag for it (0 if it has none; a hate's tags read backwards, as in LOVES AND
#                             HATES). Needs a #: without one, {evil} is the speaker's trait, as in TAGS.
#                             age reads a word's {years = n} (its age in years, put on the age scale: -1 at 18 or
#                             under, 1 at 80 or over), else its {age} tag. {years} does nothing but this: it doesn't
#                             lean who picks the word. Pick tags are always on the -1 to 1 scale, age too — years are
#                             only for {years} and the speaker's own comparisons (age > 50, other.age < 30).
#     man / woman             the word's {sex = man} or {sex = woman} (1 / -1, the other way round for woman; 0 if
#                             not given). {sex} only describes the word: it doesn't lean who picks it.
#     fancies                 how drawn the speaker is to the word, by its {sex}, theirs and their gay trait (people/
#                             about.txt): 1 the sex they go for, -1 the other, 0 if they're bi or either sex isn't
#                             known. A word without {sex} is always 0. Needs a #, like a trait.
#     several, joined by + or -  their weighted average, still about -1 to 1. - turns a term round (as = -1 would);
#                             a number in front weights it (2likes counts twice, 0.5evil half). Always needs a #.
#                             Every term reads the words; to weigh the speaker's own traits as well, give those as
#                             their own tags beside it (TAGS), and each leans or limits on its own.
#   Picks (after the measure, any number of #s, run together or spaced):
#     (none)                  the last word picked in the line being replied to (likes only)
#     #n                      the word held as #n, whatever its category: [folk#1] and [animals#1] are both #1, so keep
#                             each number to one word in a conversation
#     #1#2#3                  several held words
#     #all / #any / #mean     with no numbers: every word held with a #n so far in the conversation
#   Mode (one more #, anywhere among the picks; all if none):
#     #all                    every one must pass a limit (the level is the lowest of them)
#     #any                    at least one must (the highest)
#     #mean                   their average must
#   Then, as with likes: no value or = n leans (soft), < > <= >= n limits (hard). Several pick tags can be given at once;
#   each counts separately. With none of its picks held, a pick tag's level is 0.
#
# MOST AND LEAST: a placeholder that says one of the held words, ranked by a measure:  [most: measure#picks, options]
#   [most: …] / [least: …]    the word that measures highest / lowest, for the speaker
#   [most2: …] [least3: …]    the 2nd, 3rd... (the line isn't said if there are fewer words)
#   The first option is the measure and picks, as in PICK TAGS (no picks: every word held so far; the mode doesn't
#   count); the rest are the usual call options (forms, a, lower...). Ties are broken at random.
#   In one line, each [most]/[least] skips any word another has already chosen, moving on down its own ranking
#   ([most2] after [most] is still the 2nd, unless that was taken). They fill left to right, so the first gets first choice.
#   One held with a #n ([most#5: …]) also skips any word held by another [most#n]/[least#n] earlier in the
#   conversation, so a later round of choices never repeats an earlier one.
#   [most#4: …]               holds the word it chose as #4, like any pick: later lines say [most#4] for the same word,
#                             and pick tags read it as #4. A reply's measure is the replier's, not the first speaker's.
# Questions and remarks about the other person should be limited like this, so nobody asks why a smiling person's
# crying. In a reply, the other person is whoever said the line above it: "You make me so mad. > Why are you crying?"
# asks the first speaker.
#
# SEEN: something the speaker saw happen to someone else in the last 60 seconds (hard limits)
#   {seen}                    anything                        {seen = drowned}  that one thing
#   {seen = death}            any death                       {seen = punch, evil}   a punch, leaning toward the evil
#   Deaths: killedbycar, beatentodeath, smited, drowned, exploded, crashedinto (a car smashed into the building they were in), fell (a fall from high up), punchedfence (bled out punching a fence), orbsmited (a Seraphorb struck them down with its lightning: only villains)
#   ({seen = death} is any of them). Others: punch (someone
#   punched), knockedbycar (hit, not killed), planecrash (an aircraft blew up nearby; [seen.name] means nothing), beeattack (a bee stung someone, knocking them down), resurrected, healed (a MedBot patched them up), orbhunt (a Seraphorb, a flying chrome orb, stopped over [seen.name]'s head, humming, about to smite them), waterwalking, smelly (a smelly person near), nude (a nude person near). Anyone near
#   enough (or in the same building) sees it; a death isn't replaced by something lesser while it's fresh.

#   {felt = revenge}          they just punched whoever last punched them (within 2 minutes)
#   {felt = stung}            a bee stung them (and knocked them down)

#   {felt = haircut}          just had a new haircut at a salon (a new style, maybe a new colour, maybe shaved)
#   {felt = newclothes}       just came out of a clothes shop's changing room in new clothes

#   {felt = gifted}           was just given something (the Gift button on their card: see assets/text/gifts.txt)
#   {felt = cheered}          was just given something that cheered them up out of a sad or angry mood
#   {felt = dined}            just finished a meal at a restaurant

#   {felt = scavenged}        picked up a dropped coffee, pint, hot dog or the like off the ground to finish it (mostly those
#                             craving it: stimulants for coffee, alcoholic for a pint — src/life/people/peopleHolding.js)

#   {felt = ruined}           had their snack or drink knocked from their hand, and left it lying there

#   {felt = mugging}          (evil) about to punch someone for the coffee, pint or food in their hand ([felt.item]),
#                             to grab it and run ([felt.by] is who)
#   {felt = robbed}           had their knocked-down snack or drink snatched (may go after the thief: revenge roll)
#   {felt = carcrash}         was inside when a car smashed through the wall; ran out as the building came down
#   {felt = healed}          a MedBot just healed them back to full health (see src/life/medbot.js)

#                             see the party in src/life/people/peopleActivities.js)

# Seeing or feeling something, people say a line from reactions.txt straight away — once each — before anything else:
# aloud (in a conversation or on their own), unless it's tagged {thought} and they're on their own, or they're out of
# hearing, when it's a thought. {seen} and {felt} work on any line anywhere.
#
# NAMES: [me.name] the speaker, [other.name] who they're talking to, [seen.name] who it happened to, [seen.by] who did
# it, [felt.by] who did it to the speaker (for revenge, who they got back at). A line whose name can't be had isn't said.
# [felt.item]: the dropped thing a {felt = scavenged/leftlitter/reclaimed/ruined/snatched/robbed/mugging} line is about ("coffee",
# "pint", "hot dog", "pizza slice", "souvlaki").
#   Catch you later, [other.name]. {end}
# STRANGERS' NAMES (automatic — write [seen.name] as usual): [seen.name], [seen.by] and [felt.by] give the person's name
# only if the speaker's been introduced to them (finished a conversation together); otherwise "that man" or "that
# woman", by their sex — never a description ("that man in the red hat"). It takes a capital at a sentence's start
# like any word:
#   [seen.by] just punched [seen.name]!   → "That man just punched that woman!" (neither known)
#                                          → "That man just punched Al Smith!" (knows Al, not the puncher)
#   Oh God, [seen.name] drowned...        → "Oh God, that woman drowned..."
# [other.name] is different: to a stranger the whole line isn't said ("Catch you later, that woman" reads wrong), so
# lines using it only come up between people who've met. [me.name] is always the speaker's own name.
#   [seen.by] just punched [seen.name]! {seen = punch}
#   Ow! What was that for, [felt.by]? {felt = punched}
# LOVES AND HATES BY NAME: [me.loves], [me.hates] one of the speaker's own; [other.loves], [other.hates] one of who
# they're talking to's: the entry as they say it (filled in for them — see above), with its tags.
# Hold one with #n; replies' {likes} read it like any word. A line isn't said if they've none.
#   Actually, I hate [me.hates] more.
#   > [me.loves#1]. >> Really? [me.loves#1]? {likes #1 < 0}
#   You love [other.loves], don't you? {nosy}
# [both.loves], [both.hates]: one the speaker and who they're talking to share; [both.clash]: one the speaker loves and
# the other hates. Not said unless there is one, so these lines only come up when true.
#   We both love [both.loves], don't we? {chatty}
#   At least we agree [both.hates] is awful.
#   How can you hate [both.clash]?
#

# LOVES AND HATES
# When a [placeholder] is filled, an entry that is one of the speaker's loves (any of its forms, same words, any case —
# "Snakes" is snake) is picked half the time, however big the category; one of their hates is never picked. In a
# [x: hated] call it's the other way round: hates half the time, loves never.

# ENDING A CONVERSATION
#   {end}                     once said, the conversation ends well: the two wave goodbye (a circle: the speaker leaves)
#   {end = bad}               ends it badly: no wave, and each may go for the other (more likely the more aggressive)
#   Alright, bye then! {end, patience}          Get out of my face. {end = bad, aggression}
#   > Leave me alone. {end = bad, patience = -1}  a reply that ends it
# SCORE: how the conversation's going. {score = n} on a line adds n when it's said; at the end, each point moves how
# they feel about each other (the Social tab) by 3, on top of the usual. Closers can go by it:
#   > Oh, me too! {likes > 0, score = 1}        > You would. {likes = -1, score = -1}
#   Lovely chatting! {end, talk.score > 1}      Well, that was unpleasant. {end = bad, talk.score < -1}
#   {talk.score = -1}         leans toward a conversation that's going badly (score -3 counts fully)
# WALKING TOGETHER: two who've just waved hello sometimes walk on side by side instead, talking as they go ({is = walking}),
# then stop to wave goodbye and part; whoever's possessed walking off mid-chat is followed the same way.
# ON A BENCH: someone sat on a bench now and then talks with whoever's sat beside them — the same as any two chatting,
# only neither turns or waves, and neither gets up till it's finished. Ended rudely ({end = bad}), both stand up off
# the bench and the usual punch chance plays out.
# DIALOGUES: a line with replies is said to one person (whoever the speaker's facing), and only they answer it; the
# answer's replies go back to the first, and so on — a third person never joins in (they'd answer as if asked). Nobody
# leaves, or says a closer, while a dialogue's waiting on its next line: it runs until no reply fits (or nobody answers
# within a few seconds).
# IN A CIRCLE (people sat on the grass): calls go to whoever the speaker's facing (see DIALOGUES). When someone joins, one of those sat there who isn't
# mid-line greets them with a line from greetings.txt (other. is the newcomer), in the gap after the line being said —
# never cutting in — and then any dialogue picks up where it was (a greeting's own replies only come when none is going
# on); the rest look round at them. Whoever's possessed going up to someone (E) greets them
# the same way (standing, so a circle-only greeting takes {is = sitting}), and they reply — sat down, they stay sat. Someone whose time's up there gets the next turn to
# say a closer before getting up: {end} and they wave to the rest; {end = bad} and they walk off, rolling the punch chance
# only against those in the circle they already felt
# badly about (going for each they rolled, one after another), while each of those who dislikes them rolls against
# them. Anyone the fight got up (not the leaver) goes back to the circle once they've calmed down, if it's still there.
# Punches from a conversation gone bad (either kind) don't send bystanders running or joining in: they just see it
# ({seen = punch}) and talk about it — "What was that about?". Other punches still scatter people.
#   Put them on replies to cut a conversation short ("> Mind your own business. {aggression, end = bad}") — an ending
#   line's own replies are never said. When a conversation's time is up, someone says a line from closers.txt; if
#   none is said within a few seconds, they just wave.
#
# CONVERSATIONS
#   I slept well last night.              a call (the opener)
#   > That's so great! {evil = -1}         replies to it, picked by the replier's traits
#   >> Thanks!                             replies to the reply above it, and so on
#   > [dismissal]                          a reply can be an include
# The talkers take turns round their chat circle. If nothing fits, they babble instead.
#
# JUMPS: a branch can rejoin another line anywhere, in this file or another.
#   {as = name}               names this line (letters, numbers, _), so a {then} can reach it. Each name once per file.
#   {then = name}             the next line said is the one named, by whoever's turn is next, and the conversation goes
#                             on from that line's replies. Its own > replies are never said (a warning says so).
#   {then = file@name}        the line named in another file (the file's name, as for a [category]).
#   {now = name}              the line named is said on the end of this one, by the same speaker, in the same bubble
#                             (filled in as if written there), and the conversation goes on from its replies. With
#                             no text of its own ({now = name} alone on a line) it just says the named line. If the
#                             named line can't be said (its tags don't fit, a placeholder can't be filled), neither
#                             is this one. Its own > replies are never said. file@name as for {then}.
#   A line can have both: {now} first, then {then} decides what comes next.
#   On an include ([dismissal] {then = name}), every line it brings jumps there.
#   The named line keeps its own tags: if they don't fit whoever's next, nothing's said and the conversation stalls
#   there, as when no reply fits. #n picks are kept across a jump, so a line jumped to sees whatever's held by then:
#   a line reached from several branches should only use #n's every one of them sets.
#   A conversation follows at most 8 jumps ({then} and {now} both count); past that, a {then} or {now} is left off and the line ends the conversation (so a loop can't go on forever).
#   A {then} naming no line warns once when the files load.
#

# NOTES (answers to questions that have come up)
# - New files and folders need no code changes: serve.py lists whatever's there. Serving some other way (another port,
#   python -m http.server, Live Server) it can't, so run `python3 serve.py --index` after adding files, or new
#   categories 404.
# - A line that's only [category] in people/loves.txt or hates.txt is read as a section heading and cuts off every entry
#   below it — put a placeholder inside words instead ("Their [pets: plural]").
# - In people/ files { } are traits and [ ] placeholders (whole-line [Headings] aside), as everywhere else now.
# - A love or hate's {traits} are what holding that opinion does to someone.
#   In speech, a hate said as the opposite ("I love slow walkers") leans the other way: the fast hate slow walkers, so
#   the slow are who'd say they love them. That's all speech does with them — persist doesn't change it; for a hard
#   rule on who says something, use a speech.… tag.
#   Drawn into the other list ("Conversely, [hates]" as someone's love), its traits are turned round (×1.7 → ×0.59,
#   +0.5 → −0.5, ×0 → the trait's max: "Conversely, the law" {outlaw = 0} makes a full outlaw; erratic and normal turn
#   into each other: erratic 1 → normal ×20, erratic 0.5 → normal ×4.5, normal ×2 → erratic 0.23; a switch is dropped, as loving the opposite can't switch it off), except any that persist, which stay
#   as written because they go with the subject whichever way you feel:
#     Hate: Slow walkers {speed = 1.7}              haters are fast; "Conversely, slow walkers" makes someone slower
#     Hate: Walking so fast {speed = 2, persist}    loving it makes you fast too
#     Hate: Men {aggression = 2, persist = aggression}   only that trait persists (several: persist = a, persist = b)
#     {…, persist, flip = mood}                     all persist but mood, which turns round (several: flip = a, flip = b)
#     {…, noflip} / {…, noflip = speed}             dropped instead: taken the other way round, it (or that trait) does
#                                                   nothing at all (noflip wins over persist)
#     Hate: Other socialists {conservative = -0.3, persist = conservative, speech.conservative < 0}
#                                                   left-wing, loved or hated; and only left-wingers say it
#   Each entry stands alone: hating "being an alcoholic" is its own entry, and says nothing about "alcoholics".
# - speech.… in a people/ entry's { } is a speech tag, as in any speech file ({speech.appeal = 0.5}, {speech.evil},
#   {speech.conservative < 0}); everything else there is a trait. It's the mirror of effect.… on a speech word.
# - A love or hate drawn into the other ("Conversely, [hates]") is never one the person already holds either way; if
#   there's nothing left to draw, that entry's dropped from them (unless it's all they have).
# - The same words in loves and hates stay two entries, each leaning its own way.
# - A filled-in love or hate ("Their [pets]" → cats) gives the person only the entry's own {traits}, whatever word
#   filled it; the word counts as loved (or hated) in speech, and the card and spoken wordings use the same pick.
# - Tag strengths aren't capped: {evil = 2} leans twice as hard. The speaker's level is always -1 to 1.
# - {weight: 4} reads as {weight = 4}: a colon works as = in any tag.
# - {appeal} has no automatic evil flip: a villain only likes something shunned when a tag says so ({appeal = -1, evil}).
# - {score} only comes from lines you tag — {likes} adds none by itself. A conversation's time running out only prompts
#   a closer; a low score never ends it badly by itself (only {end = bad} lines do).
# - [both.clash] in a reply is between the replier and who they're answering: something the replier loves and the
#   other hates. Hold it with #1 to keep the first speaker's word.
# - speech/words/locations/buildingsPlaceNames/ holds name parts nothing ever says: [offices] names the city's offices,
#   each one a company ("Epic Systems", "Splort!"), [residential] its homes ("Silva Residential", "Tanaka Flats"),
#   [industrial] the yards of its industrial zones ("Dusty Revolver Mill", "Steel Badger & Sons Import & Exports") and
#   [streets] the streets its town and suburb houses are on ("No. 4213, Smith's Road"), which their cards carry on their
#   Name row (the title bar still says what the building is: a Warehouse, a House — see buildingOwnName and pickedName in
#   src/buildings/building-types.js). A house's street is picked per *zone*, not per house, so every house in one zone is
#   on the same street; a house that's a pub, a salon or a clothes shop is one of those instead and keeps its own name.
#   Each is picked with the building's own number as the seed, so a building always has the same name, and each file's
#   own line composes the name out of the words in these files ([corpTitle] [corpType], [corpTitle] [residentialType]),
#   so their {weight}s, [placeholders] and nesting work as everywhere else. The name is said as the line reads but for
#   its first letter, which is raised ("splort!" reads "Splort!"); any capital further in has to be written in the file.
#   One of corpTitle's lines names nothing as the files stand: there's no fruits.txt — the list is [fruit].
# - A new opener (a one-liner or anything else) never cuts into a conversation tree: while a line waits on its answer,
#   the one it was said to answers it (straight away, dropping their babble) and nobody else starts anything.
