# What each kind of building is like: what its card says when you click one in World mode. Edit freely, then reload the page.
# Each [section] is a kind of building. Under it, `attribute = value` lines:
#
#   name    what it's called on its card (followed by its own number, like "Warehouse #4821")
#   title   its own name, on the line under that (a pub's "The Red Lion"): left out, there's no second line
#           A title can say how it's lettered on a shop sign in a mall, in brackets after it:
#             title = The Red Lion {font = Georgia, color = #f2d27a, backcolor = #1d2340}
#           `font` is any typeface the browser has (put italic, bold or a weight like 900 in front if wanted:
#           `font = italic Brush Script MT`); `color` is the lettering's, as a hex code; `backcolor` the cladding it's
#           on, also a hex code. Leave any out and the sign picks its own. The brackets never show on the building's card.
#   mood    its current mood, usually an emoji
#   loves   what it loves
#   hates   what it hates
#
#   enterable   `yes` if people go inside this kind and are gone a while (see "going indoors" in src/life/people/people.js).
#               Left out, it's no: somewhere you'd only ambiguously go into (a container yard) shouldn't swallow people.
#
# Give an attribute several lines to have each building of that kind pick one of them (always the same one for the same
# building). A kind falls back to the zone type that puts it up, and then to [default], so a section need only say what
# it does differently. Blank lines and lines starting with # are skipped.
#
# The kinds, by the zone type they belong to:
#
#   buildings    landmark
#   industrial   warehouse, factory, tankfarm, containeryard
#   farmland     farmstead
#   suburbs      house
#   town         terrace, pub, salon, clothes (any other shopfront is a terrace)
#   airport      terminal, hangar, controltower
#   mall         clothes, salon, pub (the same kinds as a town's, each a unit off the concourse), vacant
#
