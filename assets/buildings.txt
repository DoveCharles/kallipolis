# What each kind of building is like: what its card says when you click one in World mode. Edit freely, then reload the page.
# Each [section] is a kind of building. Under it, `attribute = value` lines:
#
#   name    what it's called on its card (followed by its own number, like "Warehouse #4821")
#   mood    its current mood, usually an emoji
#   loves   what it loves
#   hates   what it hates
#
# Give an attribute several lines to have each building of that kind pick one of them (always the same one for the same
# building). A kind falls back to the zone type that puts it up, and then to [default], so a section need only say what
# it does differently. Blank lines and lines starting with # are skipped.
#
# The kinds, by the zone type they belong to:
#
#   buildings    landmark
#   industrial   warehouse, factory, tankfarm, containeryard
#   farmland     farmstead
