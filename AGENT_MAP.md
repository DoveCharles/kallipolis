# Agent map — Kallipolis

Browser city-blockout tool on three.js (plain ES modules, no build step). Read this first; open only the files you need.

## Rules for agents
- Never list or search `.git/` or `assets/models/` (binary .glb, ~14 MB). Exclude them from any recursive listing.
- Search (grep) for a symbol, then read only the relevant line range. Files over ~40K are marked **big**; never read those whole.
- `S` / `App` in `src/core/shared.js` hold cross-module state; start there when tracing data flow.
- Update this map in the same change whenever files are added, moved, renamed or deleted.
- Versioning: `.githooks/pre-commit` runs `tools/version.py` on every commit — a random 2-word version name from assets/text/speech/words in the title bar (`#version`, index.html), to confirm a push is live. Each clone enables it once: `git config core.hooksPath .githooks`. Don't run it by hand.
- Log notable decisions in the project doc `claude/decisions.md`.
- Speech (`src/life/speech-text.js`, format in `assets/text/speech/about.txt`) must know about new things people could talk about. When adding or changing a way people die or something people could notice (a `cause` in killPerson/drownedPerson, or a witness/notice/feel call in people.js → SEEN_RANK there, SIGHTS/DEATHS/FEELINGS in speech-text.js), a trait (TRAITS — read automatically, but list any worth mentioning in about.txt), a world value (weather, time, morality → WEATHERS / worldAllows), a building kind or room layout (`here.building`), or anything else a line could react to: update speech-text.js and about.txt's lists, and add example lines.
- Speech tags and word tags: don't lean on the face/emotion traits (happy, sad, angry, crying, blushing, fuming, partying, singing, drowsy, sweating, panicking, starstruck, goofy...). They're short-lived face states only ~1 in 20 people have, so lines keyed to them almost never come up. Use the lasting traits instead: partying → alcoholic, stimulants; sad → mood < 0; nerdy → nerd; plus evil, aggression, conservative, outlaw, stoner, psychs, painkillers, smoker, chatty, patience, age. Never use crazy (renamed erratic, which only adds emotional swings; don't use it as a descriptor).
- Saving: when adding state the player would notice losing, decide whether it belongs in the project file — the same test as the browser session (autosave): kept if it's kept there, not if it isn't. Through `serializeProject`/`loadProjectFromData` in `src/project/save-load.js`: player progress (energy, money, morality points, daily gift, identified traits, paid possession time, quests, tech tree) in `src/project/progress.js` (getProgress/setProgress/onProgress); the crowd and cars, their ids, looks and positions, in `peopleKeep.js`/`carKeep.js`; favourites in `ui/favorites.js`. Not worth keeping: what any unhearted person or car makes up again or shrugs off (needs, moods in passing, what they're doing, a fright) — favourited ones may keep more. Never undo it (history.js drops progress, crowd and traffic); an older file without it should start fresh, not keep the last city's.

## Root
- `.githooks/pre-commit` Renames the version (tools/version.py) and stages index.html on every commit.
- `index.html` (22K) Page markup, panel DOM, importmap (three.js from CDN), Clipper from CDN. Links the CSS below.
- `css/` Styles, linked in cascade order: `base.css` (core layout, panel, cards), `win3.css` (Windows 3.0 theme, `html.win3`; also `.use-label`, the possessed person's "Press E" label), `touch.css` (touch & small screens), `phone.css` (≤760px: same win3 window, panel over the view, cards span the bottom), `ped.css` (possession/driving view).
- `style.css` Stub; unused (split into `css/`). Safe to delete.
- `src/ui/meter.css` Reusable meter component. `src/ui/morality.css` superseded, unlinked.
- `serve.py` Dev server with no-store caching: `python3 serve.py [port]`. Also writes `assets/text/index.txt` (every .txt under assets/text/, for the speech loader) and `assets/music/index.txt` (every .mid under assets/music/, for audio/pub-music.js) on start and whenever they're fetched; on start looks up missing YouTube loudness for tv.txt into `assets/tv-loudness.json` (the TV's levelling, buildings/interior.js); `python3 serve.py --index` only writes them. `.claude/launch.json` lists ports 8743–8753.
- `worlds/*.json` Project files shared by link: index.html?world=NAME (project/autosave.js).
- `netlify.toml` Deploys repo root as-is; push to `main` redeploys.
- `README.md` Feature overview. `jsconfig.json` JS type-check settings for `src/`.

## assets/
- `text/*.txt` Editable data read by `src/core/entries.js`: `text/people/` (one file per list: `about.txt` — notes, trait table, [distribution] — `boynames`, `girlnames`, `unisexnames` (into both), `surnames`, `nicknames`, `moods`, `loves`, `hates`; joined in order under their headings by life/profiles.js PEOPLE_FILES), `gifts.txt` (what the Gift button gives: read by src/life/gifts.js), `cars.txt`, `buildings.txt`, `bees.txt`, `pigeons.txt`, `planes.txt`, `boats.txt` (per boat kind), `trains.txt`, `tv.txt` (YouTube links or direct video file URLs), `morality.txt`, `pronounce.txt` (words SAM says wrong, as phonemes or respellings: audio/speech.js spell), `text/index.txt` (generated by serve.py; commit it). `music/` The pubs' music: drop any `.mid` in (subfolders too) and every pub plays it (audio/pub-music.js), except `music/restaurant/` (and `restaurant-greek/`, `restaurant-sushi/`): restaurants' quiet background music only, and `music/convenience/`: convenience stores', through a tinny speaker; `music/index.txt` is generated by serve.py (commit it); `music/TimGM6mb.sf2` is the General MIDI sound bank they're played with (Tim Brechbill, GPL v2). `text/speech/` (what people say and think, in subfolders as you like — subjects like [tastes] come from <tastes> on people's loves/hates; words/topics/topics.txt gathers them: one category per file, named by file — words with forms, conversations with > replies, thoughts, {tags}, world limits, loves/hates; format in `speech/about.txt`; read by src/life/speech-text.js). `dictionary.txt` is unused (replaced by speech/).
- `icons/*.png` Every UI icon (and each coloured state: `-on`, `-open`, `-hidden`) as a hand-drawn 16x15 bitmap, shown in place of the SVGs by src/ui/pixel-icons.js; pure black pixels take the text colour. All preloaded by a list in index.html's head: add new icons there.
- `models/*.glb` Blender exports (people, hair, outfits, furniture sets, vehicles). Generated by `tools/*-models.py`.

## Source files
Format: `file` (size) purpose — key exports.

### src/
- `main.js` (8K) Entry point: imports every module in load order, then runs the render loop. The world's updates (people, traffic, critters, trains, day/night, weather…) get the world clock `w`, stopped while S.interactionMode isn't 'move' (edit mode: the world frozen) or the loading screen's up; water, lights, sound and camera shake keep real time.
