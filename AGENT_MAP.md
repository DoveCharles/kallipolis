# Agent map — Splinetopia

Browser city-blockout tool on three.js (plain ES modules, no build step). Read this first; open only the files you need.

## Rules for agents
- Never list or search `.git/` or `assets/models/` (binary .glb, ~14 MB). Exclude them from any recursive listing.
- Search (grep) for a symbol, then read only the relevant line range. Files over ~40K are marked **big**; never read those whole.
- `S` / `App` in `src/core/shared.js` hold cross-module state; start there when tracing data flow.
- Update this map in the same change whenever files are added, moved, renamed or deleted.
- Log notable decisions in the project doc `claude/decisions.md`.

## Root
- `index.html` (22K) Page markup, panel DOM, importmap (three.js from CDN), Clipper from CDN. Links the CSS below.
- `css/` Styles, linked in cascade order: `base.css` (core layout, panel, cards), `win3.css` (Windows 3.0 theme, `html.win3`), `touch.css` (touch & small screens), `phone.css` (≤760px layout), `ped.css` (possession/driving view).
- `style.css` Stub; unused (split into `css/`). Safe to delete.
- `src/ui/meter.css` Reusable meter component. `src/ui/morality.css` superseded, unlinked.
- `serve.py` Dev server with no-store caching: `python3 serve.py [port]`. `.claude/launch.json` lists ports 8743–8753.
- `netlify.toml` Deploys repo root as-is; push to `main` redeploys.
- `README.md` Feature overview. `jsconfig.json` JS type-check settings for `src/`.

## assets/
- `*.txt` Editable data read by `src/core/entries.js`: `people.txt` (names, moods, likes, traits — trait syntax at top of file), `cars.txt`, `buildings.txt`, `bees.txt`, `planes.txt`, `trains.txt`, `tv.txt`, `morality.txt`, `dictionary.txt` (real spoken lines).
- `models/*.glb` Blender exports (people, hair, outfits, furniture sets, vehicles). Generated by `tools/*-models.py`.
